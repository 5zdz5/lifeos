# LifeOS 部署与安装（最简单）

目标：把 LifeOS 装到平板上，像 App 一样用。**不需要签名、不需要 DevEco、不需要 HTTPS 证书。**

## 三种方式一览

| 方式 | 难度 | 需要什么 | 适合场景 |
| --- | --- | --- | --- |
| **A. 局域网一键** | ⭐ | 一台电脑 + 平板同 WiFi | 最快体验、临时/演示用 |
| **B. 单文件离线** | ⭐ | 任意方式传 1 个 html 到平板 | 长期用、最省事、可完全离线 |
| **C. 鸿蒙原生 HAP** | ⭐⭐⭐ | DevEco + 华为开发者签名 | 正式原生 App、上架分发 |

> 推荐顺序：**先 A 体验 → 满意后用 B 长期用**。两者都是同一套 Web 应用，功能完全一致。

---

## 方式 A：局域网一键（推荐先试）

1. 在电脑上进入 `lifeos` 目录，运行：
   ```bash
   bash start.sh          # 或 ./start.sh，可用 bash start.sh 9000 指定端口
   ```
2. 终端会打印两行地址，并显示一个**二维码**：
   ```
   电脑本机 :  http://localhost:8080/
   平板访问 :  http://192.168.x.x:8080/
   ```
   （如果电脑无网络、装不了二维码库，会改为直接打印 URL，不影响使用——手输即可。）
3. 平板连**同一个 WiFi**，用相机或浏览器**扫二维码**（或手输上面的地址）打开页面。
4. 平板浏览器菜单 → **「添加到主屏幕」** → 名称填 `LifeOS` → 完成。
5. 平板桌面出现 LifeOS 图标，点开即**全屏无地址栏**的独立应用，之后离线也能用。

> 停止服务：在电脑上 `Ctrl + C`。

---

## 方式 B：单文件离线版（最省事、可长期）

文件位置（二选一，内容相同，约 65 KB）：
- `lifeos/dist/lifeos.html`
- `lifeos/src/standalone.html`

步骤：
1. 通过**微信文件传输 / 数据线 / 网盘 / 邮件**等任意方式，把这个 **单个 html 文件**传到平板。
2. 平板上用**浏览器打开**该文件。
3. 浏览器菜单 → **「添加到主屏幕」** → 完成，桌面上就有一个 LifeOS App 图标。
4. 之后无需服务器、无需联网即可打开（默认演示模式）；联网后在 ⚙️ 设置里填 AI 接口即可真实调用。

重新生成该单文件：
```bash
node build-standalone.js
```

---

## 方式 C：正式鸿蒙原生 App

见 [`INSTALL.md`](./INSTALL.md)：用 DevEco 打开 `lifeos-harmony` 工程，自动签名后 `Build → Build APP(s)` 生成 `.app`/`.hap`，再装到平板。

---

## 方式 D：PWA 一键托管（最持久的可安装链接）

如果你想**不依赖电脑开机、也不用给每人传文件**，就让任意平板/手机通过一个链接安装 LifeOS，用本方式：一条命令部署到免费 HTTPS 静态托管，生成的 PWA 链接长期有效、可离线、全屏如 App。

文件：`lifeos/deploy.sh`

步骤：
1. 电脑上装好 **Node.js**（已装可跳过）。
2. 首次部署前登录平台（选 Netlify / Vercel 时需要）：
   ```bash
   npx netlify-cli login     # 或 npx vercel login
   ```
   Surge 无需登录，部署时填邮箱 + 密码即可。
3. 运行并交互选择平台：
   ```bash
   bash deploy.sh            # 可选 Netlify / Vercel / Surge / GitHub Pages
   ```
4. 命令结束会输出一个 **https://…** 地址。平板浏览器打开 → 菜单「添加到主屏幕」→ 完成。
5. 该链接从此就是一个**可安装的 PWA**：全屏、可离线、桌面有图标。

> 仅本机自检 / 体验（不起公网）：`bash deploy.sh --preview` 会起本地服务，访问 `http://localhost:8088/`。
>
> 说明：本沙箱无公网账号与 npm 部署权限，无法在此代你完成真实部署；脚本与托管目录（含合法 `manifest.webmanifest` / `sw.js`）均已就绪，你在本机执行 `bash deploy.sh` 即可。

## 使用要点

- **AI 配置**：首次打开是「演示模式」（AI 返回示例回复）。打开 ⚙️ 设置，填入 **OpenAI 兼容接口** 的 `Base URL` / `API Key` / `模型名`（支持 DeepSeek、通义、智谱等），保存后即真实联网调用。
- **数据安全**：所有任务 / 习惯 / 笔记 / 对话都存在**本机**（浏览器 `localStorage`），不联网、不上传。
- **「添加到主屏幕」才是关键**：无论 A 还是 B，只有执行了这一步，LifeOS 才会以全屏 App 形态出现在桌面；否则只是个网页书签。
- **平板宽屏**：界面已做 `@media (min-width:1100px)` 宽屏适配，横屏体验最佳。

## 常见问题

- **平板打不开局域网地址**：确认电脑和平板连的是**同一个 WiFi**（部分公共 WiFi 会隔离设备，可改用手机热点）；或改用方式 B。
- **「添加到主屏幕」找不到**：鸿蒙/安卓用**系统浏览器或 Chrome/Edge** 打开；QQ/微信内置浏览器可能无此选项，点右上角「用浏览器打开」即可。
- **数据没保存**：方式 B 在个别平板的 `file://` 下存储可能受限，改用方式 A（HTTP 访问）最稳。
