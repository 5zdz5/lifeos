# 早期部署方案（已归档）

这里是项目演进过程中做过的**备用/实验性部署方式**，现已不是推荐路径，保留供查阅，日常使用不需要。

当前推荐路径只有两条，见主 [`README.md`](../README.md)：

1. **在线链接**（PWA，自动更新，可「添加到主屏幕」）
2. **`dist/lifeos.html` 单文件离线版**

| 文件 | 原用途 | 为何归档 |
| --- | --- | --- |
| `start.sh` | 局域网一键起服务 + 终端二维码，平板扫码打开 | 需要电脑开机且同 WiFi，已被在线链接取代 |
| `deploy.sh` | 交互式部署到 Netlify / Vercel / Surge / GitHub Pages | 需要公网账号，沙箱内无法代跑；现由统一发布通道承担 |
| `DEPLOY.md` | 四种安装方式的详细步骤与故障排查 | 与「简单易安装」相悖，主 README 已收敛为两条 |

鸿蒙原生工程（`/workspace/lifeos-harmony/`）及其 `INSTALL.md` 属于另一条独立路线，未在本目录归档范围内。
